# Contributing

Use Node.js 24 or later. Clone this repository and run `npm ci`, `npm test`,
`npm run check` and `npm run example`.

Open an issue that states the expected behavior and includes a small synthetic
reproduction. For fixes, submit a pull request with a concise description and
a regression test for the failure. Keep the library independent of a question
bank, account service, payment provider and hosting platform.

Preserve complete five-question passages, response-validation semantics,
unaided scoring, and documented revision intervals unless the change explicitly
updates the contract and its tests. Add authoring formats only with validation,
scoring, learner projection and declaration coverage.

Use newly written synthetic fixtures. Do not submit copyrighted exam questions,
private question banks, personal data, credentials, production identifiers or
provider logs. Changes to the publication allowlist require a deliberate review.

Contributions are made under the repository's AGPL-3.0-only license. Preserve
copyright notices for imported or adapted code and identify third-party sources.
No contributor agreement or ownership transfer is requested.
