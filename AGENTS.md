# AptiTrail Practice Engine

This is a standalone library. Use Node.js 24 or later and run `npm ci`,
`npm test`, `npm run check` and `npm run example` before proposing a change.

Keep the package independent of AptiTrail's commercial application and question
bank. Use only synthetic or newly authored examples. Do not introduce private
data, credentials, deployment configuration or provider integration code.

Update declarations and documentation when the public API changes. Preserve
passage integrity, strict response validation and help-aware scoring. Add
regression tests for behavior changes.
