# Changelog

## 0.1.0 — initial release candidate, 14 October 2026

- Extracted response validation, scoring, balanced practice selection, bookmark
  passage expansion and revision scheduling from AptiTrail.
- Added deterministic random and clock inputs, input-bank validation and ESM
  TypeScript declarations.
- Corrected empty scoring and fixed-free mixed selection, and rejected duplicate
  and unknown attempt question IDs.
- Added independent sample questions, regression tests, contributor guidance and
  a publication allowlist.

This file records a release candidate. Publication and GitHub CI results must
be verified before announcing the public release.
