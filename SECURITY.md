# Security

Version 0.1.x is the initially supported release line.

Please report suspected vulnerabilities privately through the GitHub repository
Security tab's **Report a vulnerability** flow when private reporting is enabled.
If that option is unavailable, contact the maintainer through the contact route
listed on their GitHub profile before posting sensitive details publicly.

Send a minimal synthetic reproduction and the affected version. Do not send
real learner data, live credentials, commercial question banks or provider logs.

The maintainer handles reports as capacity permits; no response-time or paid
support guarantee is offered. Public issues are suitable for non-sensitive bugs.

The library does not implement authentication, authorization, rate limiting,
database storage, payment processing or a complete application security boundary.
Keep answer-bearing bank objects on your trusted server when answer secrecy
matters, and send a projected public question to the browser.
